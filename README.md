# Quad-Qore Agentic Analytics

A modular lakehouse and agentic analytics platform developed for KKB Hackathon 2026.

## Project Goal

The platform will collect and organize financial data from sources such as BDDK and TCMB EVDS, execute analytical tools based on natural-language questions, validate the results, and present them with traceable data sources.

## Core Components

- Data source connectors
- Bronze, Silver and Gold lakehouse layers
- Data catalog and metadata
- Agentic analytics engine
- Statistical analysis tools
- Source validation and traceability
- API and user interface

## Initial Demo Scenario

The first end-to-end scenario will compare housing loan amounts from BDDK with housing loan interest rates from TCMB EVDS.

## Project Status

Project structure and technical requirements are currently being prepared.

## Security

Credentials and API keys must never be committed to the repository. Local credentials must be stored in a `.env` file.
